## Explicacion proyecto

_El proyecto consiste en un juego mobile de Pokemón, donde el objetivo es adivinar el Pokemón misterioso haciendo uso de pistas que te brinda el juego cada vez que adivinas un pokemón. La aplicación fue desarrollada con React Native, haciendo uso de componentes reutilizables, vistas y consumiendo PokeAPI para la obtención de los datos de los pokemón._


### Requisitos de uso y ejecución del software

_El proyecto puede ser ejecutado en una computadora de manera local haciendo uso de Expo, o en un telefono celular escaneando el codigo QR usando la app de Expo GO. Además, requiere conexión a internet debido al consumo de la API, PokeAPI._
